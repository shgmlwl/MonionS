# 모니모 시니어 — 유니버설 보험금 청구 프로토타입

시니어, 몸이 불편한 분, 시각장애인도 **혼자서** 보험금을 청구할 수 있도록 만든 GUI 프로토타입이에요.
큰 글씨 · 고대비(검정+파랑) · 스크린리더 · **실제로 말을 알아듣는 AI 음성 도우미**를 담았어요.

> GUI 디자인 수업 과제 · 노희지
> 모든 이름·병원·금액·계좌는 예시예요. 사진과 목소리는 휴대폰(브라우저) 안에서만 처리되고 어디에도 저장·전송되지 않아요.

---

## 바로 써 보기

깃허브 페이지에 올리면 이런 주소가 생겨요.

```
https://<내 깃허브 아이디>.github.io/<저장소 이름>/
```

| 주소 끝에 붙이면 | 하는 일 |
| --- | --- |
| `#home` | 가입 화면을 건너뛰고 홈부터 시작 (발표·전시용) |
| `#hc` | 고대비 화면으로 시작 |

휴대폰에서 열고 공유 메뉴의 **‘홈 화면에 추가’**를 누르면 앱처럼 아이콘이 생겨요.

---

## 깃허브에 올리는 방법 (명령어 없이, 5분)

1. [github.com](https://github.com)에 로그인 → 오른쪽 위 **+** → **New repository**
2. Repository name에 `monimo-senior` 처럼 영어로 이름을 쓰고, **Public**을 고른 뒤 **Create repository**
3. 새 저장소 화면에서 **uploading an existing file** 링크를 누름
4. 이 폴더 안의 **파일과 폴더를 전부** 끌어다 놓음 (`index.html`이 맨 위에 있어야 해요. 폴더째 올리면 안 돼요)
   - `.nojekyll` 같은 숨김 파일이 안 보이면 없어도 괜찮아요.
5. 아래 **Commit changes** 클릭
6. 저장소 위쪽 **Settings** → 왼쪽 **Pages**
7. **Branch**를 `main`, 폴더를 `/ (root)`로 고르고 **Save**
8. 1~2분 뒤 같은 화면 위쪽에 주소가 나타나요. 그 주소로 열면 끝!

> 마이크·카메라는 **https 주소**에서만 켜져요. 깃허브 페이지 주소는 자동으로 https라서 그대로 쓰면 돼요.
> 파일을 더블클릭해서 바로 열면(`file://`) 화면은 보이지만 마이크와 카메라는 막혀요.

### 내 컴퓨터에서 미리 보기
```bash
cd monimo-senior
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000  (localhost는 마이크·카메라가 허용돼요)
```

## 기능

### 기본형 · 고대비형
- **기본형**: 피그마 기본 시안 그대로 (흰 바탕, 파랑 `#0066FF`)
- **고대비형**: 검정 바탕 + 흰 글자 + 파랑 `#2A82FF` 버튼. 선택하면 파랑으로 채워지고 글자는 검정.
  안내 띠(연파랑) 위 글자만 진한 파랑 `#0B3F9E`로 바꿔 대비 4.5:1 이상을 맞췄어요.
- 글자 크기 **보통 / 크게 / 아주 크게** — 버튼과 간격도 같이 커져요.
- 화면은 시안(360×780) 비율 그대로 기기 크기에 맞춰 줄고 늘어나요. 그래서 작은 휴대폰(360×640)에서도 ‘보통’ 글자로는 스크롤 없이 한 화면에 다 보여요. ‘크게·아주 크게’에서는 내용만 스크롤되고 이전·다음 버튼은 항상 아래에 고정돼요.

### 청구 흐름 (8단계)
가입(나이대 → 글자 크기 자동 맞춤) → 홈 → 청구 안내 → ① 동의 → ② 누구의 병원비 → ③ 왜 병원에 → ④ 진료 과목 → ⑤ 날짜(달력) → ⑥ 병원 → ⑦ 받을 계좌 → ⑧ 확인 → 접수 완료 → 내 청구 확인

- ⑥ 병원은 네 가지 방법이 있어요:
  - **최근에 간 병원** 누르기
  - **영수증 사진 찍기** — 진짜 카메라로 찍으면 흐림·어두움을 자동으로 검사하고, 흐리면 ‘사진이 조금 흐려요’ 화면이 떠요. 선명하면 글자 읽기(OCR)로 병원 이름을 찾아 6단계 카드로 넣어 줘요.
  - **병원 이름 말하기** — 진짜 음성 인식
  - **병원 이름 쓰기** — 버튼이 그 자리에서 입력칸으로 바뀌어요
- 어느 단계에서든 **나가기**를 누르면 저장되고, 홈에 ‘작성하던 청구가 있어요 · N단계까지 저장됨’이 떠요.

### AI 음성 도우미 (오른쪽 아래 버튼)
- AI가 **소리 내어 질문**하고 → 끝나면 **자동으로 마이크가 켜져서** → **말하면 바로 알아듣고 대신 눌러 줘요.**
- 시나리오 예시:
  > AI: “AI로 보험금 청구를 도와드릴게요. 도와드릴까요?”
  > 나: “어, 도와줘”
  > AI: “좋아요. 병원 영수증이 필요해요. 준비되면 ‘다음’이라고 말씀해 주세요.”
  > 나: “다음” → 동의 → “본인이요” → “넘어져서 다쳤어요”(→사고) → “정형외과요” → “어제요” → “바른내과” → “네” → “응” → “청구해 줘”
- **화면을 보지 않아도 되도록** AI는 ‘아래에서 고르세요’라고 하지 않고, 고를 수 있는 것을 항상 말로 불러 줘요.
  - 본인 확인에서 “아니요”라고 하면 → “가족분 병원비인가요, 아니면 정보가 바뀌었나요?”로 이어서 물어요. 정보가 바뀌었으면 상담원 연결 / 계속하기를 골라요.
  - “모르겠어요”라고 하면 그 질문을 쉬운 말로 다시 풀어 줘요. (예: 뼈·관절이면 정형외과)
  - “지난주 금요일”, “11월 14일”처럼 날짜를 말로 해도 알아들어요.
  - 확인 단계에서 “고칠래” → “병원”처럼 말로 고칠 곳을 고를 수 있어요.
  - 두 번 못 알아들으면 더 쉽게 다시 묻고, 세 번째엔 상담원 연결을 권해요. 대답이 없으면 “제 말이 잘 들리셨나요?”로 다시 물어요.
- 어디서나 통하는 말: **다음 · 이전 · 다시 말해줘 · 그만 · 글씨 크게 · 고대비 · 설정**
- 말하는 동안 동그라미가 움직이고 글자가 한 단어씩 나타나서, 실제로 말하는 것처럼 보여요. 듣는 동안은 빨간색이 돼요.
- 마이크가 안 되면 대답 버튼을 눌러도 돼요.

### 스크린리더 · 시각장애 체험
- 실제 **VoiceOver / TalkBack**이 모든 버튼, 선택 상태, 진행 단계(“8단계 중 3단계”)를 읽을 수 있게 만들었어요.
- 넓은 화면(전시용 아이맥)에서는 오른쪽에 **체험 패널**이 나와요:
  - **스크린리더처럼 읽기** — Tab/화살표로 움직이면 VoiceOver처럼 읽어 줘요
  - **화면 가리기** — 화면을 검게 가리고 소리만으로 청구해 봐요
  - **지금 들리는 말** — 나오는 소리와 내가 한 말을 글자로 보여 줘요
- 휴대폰에서는 실제 VoiceOver/TalkBack을 켜고 체험하면 돼요.

## 지원 환경

| 기능 | 크롬(안드로이드·PC) | 아이폰 사파리 | 삼성 인터넷 | 파이어폭스 |
| --- | --- | --- | --- | --- |
| 화면·고대비·큰 글씨 | ✅ | ✅ | ✅ | ✅ |
| 읽어 주기 (소리) | ✅ | ✅ | ✅ | ✅ |
| **말 알아듣기 (마이크)** | ✅ | ✅ (iOS 14.5+) | ✅ | ❌ (버튼으로 대답) |
| 카메라 촬영 | ✅ | ✅ | ✅ | ✅ |
| 글자 읽기 (OCR) | ✅ | ✅ | ✅ | ✅ |

- 음성 인식은 브라우저에 들어 있는 **Web Speech API**를 써요. 크롬은 인식할 때 인터넷 연결이 필요해요.
- 처음 마이크·카메라를 쓸 때 **허용**을 눌러 주세요. 실수로 거부했다면 주소창 옆 자물쇠(ⓘ)에서 다시 허용할 수 있어요.
- 글자 읽기는 처음 한 번 도구를 내려받느라 10초쯤 걸려요. 영수증 글씨가 작거나 구겨져 있으면 틀릴 수 있어서, 읽은 내용을 고칠 수 있게 해 두었어요. 전시장처럼 카메라가 없을 땐 ‘예시 영수증으로 해 보기’를 눌러요.

## 파일 구조

```
index.html            화면 틀 (앱 + 전시 패널)
css/style.css         기본형·고대비형 색, 반응형 레이아웃
js/app.js             화면 흐름, 접근성, AI 도우미 대화
js/voice.js           말하기(TTS)·듣기(음성 인식)
js/camera.js          카메라, 흐림 감지, 글자 읽기(OCR)
manifest.webmanifest  ‘홈 화면에 추가’용
assets/               아이콘
```

**문구를 바꾸고 싶을 때:** `js/app.js`에서 바꾸고 싶은 문장을 검색해서 고치면 돼요. AI가 하는 말은 `aiCfg` 안에 화면별로 모여 있어요.
**색을 바꾸고 싶을 때:** `css/style.css` 맨 위 `:root`(기본형)와 `html[data-theme=hc]`(고대비형)의 색 값만 바꾸면 돼요.
